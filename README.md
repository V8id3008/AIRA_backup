\# A.I.R.A.

\## Artificial Intelligence for Research and Analytics



A.I.R.A. is a modular local AI assistant designed to become a fully autonomous AI operating system assistant.



\---



\## Features



\- Local LLM using Ollama

\- Long-term Semantic Memory (ChromaDB)

\- Intelligent Memory Extraction

\- Research Agent

\- Intent Routing

\- Profile Builder

\- Multi-Collection Memory

\- Duplicate Detection

\- Confidence Filtering

\## Installation



Create a virtual environment



```

python -m venv venv

```



Activate



Windows



```

venv\\Scripts\\activate

```



Install dependencies



```

python -m pip install -r requirements.txt

```



Run



```

python main.py

```
